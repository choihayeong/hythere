## 유지한 것

- 시각 아이덴티티: 네이비→흰색 그라데이션 히어로, 별·파도 애니메이션, 외곽선 이름, 바이올렛/레몬 강조색, 비스듬한 강점 카드 제목
- 콘텐츠: 경력 2건, 강점 카드 3종, 프로젝트 데이터 39건(노출 26건) — `src/data/`
- `prefers-reduced-motion` 대응, `:focus-visible` 링

## 바꾼 것 (리뉴얼 전 → 후)

- h1: "Hythere!" → 이름(Choi Hayeong). 인사말은 `<p>`.
- 섹션: 이름 없는 `<section>` → `aria-labelledby` 로 h2 와 연결
- 강점 본문: `<br>` 로 끊은 텍스트 → `<ul>`
- 프로젝트 항목: `<span>` 두 개 → `<article>` + h3 + 카테고리 Badge + 기간
- 외부 링크: 새 창 고지 텍스트(시각적 숨김) 추가, `http://` 링크는 그대로 두되 빈 링크는 비링크 처리
- 푸터 연도: 2023 고정 → 현재 연도
- 다크모드: 시스템 설정 연동(템플릿 토큰 구조 활용)
